# Marevia Jewelry Catalog

A responsive jewelry catalog built with HTML, CSS and Vanilla JavaScript.

## Features

- Responsive design
- Product search
- Category filtering
- Product gallery
- Lightbox
- Keyboard navigation
- Swipe support
- Mobile friendly

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
